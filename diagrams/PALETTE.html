Usage Guide

Element Color D2 Style
Phase boxes Low (#0d6efd) style.fill: "#0d6efd"
Decision diamonds Medium (#ffc107) style.fill: "#ffc107"
Success states Success (#198754) style.fill: "#198754"
Error states Critical (#dc3545) style.fill: "#dc3545"
Containers/Groups Background (#f8f9fa) style.fill: "#f8f9fa"
Text on dark backgrounds White style.font-color: white
Text on light backgrounds Text (#212529) style.font-color: "#212529"

D2 Examples

Phase Box (Blue)

phase1: Phase 1: SCOPE { style.fill: "#0d6efd" style.font-color: white style.border-radius: 8 }

Decision Diamond (Yellow)

check: Staged changes? { shape: diamond style.fill: "#ffc107" style.font-color: "#212529" }

Success State (Green)

complete: SUCCESS { style.fill: "#198754" style.font-color: white style.border-radius: 8 }

Error State (Red)

error: ERROR { style.fill: "#dc3545" style.font-color: white style.border-radius: 8 }

Container Group

group: "Group Label" { style.fill: "#f8f9fa" style.stroke: "#dee2e6" }

Regenerating Diagrams

To regenerate SVGs after editing D2 files:

./scripts/regenerate-diagrams.sh

The script requires D2 CLI. Install with:

# macOS brew install d2 # Linux curl -fsSL https://d2lang.com/install.sh | sh # Windows scoop install d2
